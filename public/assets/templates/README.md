# কারিয়ানা কুরআন — অফিসিয়াল আইডি কার্ড ও সার্টিফিকেট ভেক্টর টেমপ্লেট ডিরেক্টরি

এই ডিরেক্টরিতে কারিয়ানা কুরআন শিক্ষা সোসাইটির প্রাতিষ্ঠানিক আইডি কার্ড এবং সনদের মূল ভেক্টর ফাইল সংরক্ষিত হবে।

## 📁 ফাইল রাখার নিয়মাবলী:
1. **মুয়াল্লিম ও শিক্ষক আইডি কার্ড:**
   - ফাইল নাম: `teacher_id_card_template.svg` অথবা `teacher_id_card_template.ai`
   - রেজোলিউশন / অনুপাত: ৩.৩৭৫ x ২.১২৫ ইঞ্চি (CR80 স্ট্যান্ডার্ড আইডি কার্ড সাইজ - 85.6mm x 53.98mm)
   - ডায়নামিক প্লেসহোল্ডার ট্যাগ:
     - `{{TEACHER_NAME}}` - শিক্ষকের পূর্ণ নাম
     - `{{TEACHER_CODE}}` - মুয়াল্লিম কোড (যেমন: `KRN-T-1001`)
     - `{{DISTRICT}}` - দায়িত্বপ্রাপ্ত জেলা
     - `{{PHOTO}}` - শিক্ষকের পাসপোর্ট সাইজ ছবি
     - `{{QR_CODE}}` - কিউআর কোড (পাবলিক ভেরিফিকেশন লিংক: `https://project.rasel.cloud/kariana/verify/{UUID}`)
     - `{{EXPIRY_DATE}}` - মেয়াদের তারিখ (অনুমোদনের তারিখ হতে ঠিক ১ বছর)
     - `{{SIGNATURE_DIRECTOR}}` - মাওলানা সাদ্দাম হোসেন / প্রধান অ্যাডমিনের ডিজিটাল স্বাক্ষর

2. **শিক্ষার্থী সনদ ও প্রত্যয়নপত্র (Certificate):**
   - ফাইল নাম: `student_certificate_template.svg` অথবা `student_certificate_template.ai`
   - সাইজ: A4 অনুপাত (Landscape / 297mm x 210mm)
   - ডায়নামিক প্লেসহোল্ডার ট্যাগ:
     - `{{STUDENT_NAME}}` - শিক্ষার্থীর নাম
     - `{{FATHER_NAME}}` - পিতার নাম
     - `{{COURSE_NAME}}` - সম্পন্নকৃত কোর্স (যেমন: নুরানী মুয়াল্লিম কোর্স / সহীহ কুরআন শিক্ষা)
     - `{{RESULT_GRADE}}` - প্রাপ্ত বিভাগ (মুমতাজ / জায়্যিদ জিদ্দান)
     - `{{CERTIFICATE_NO}}` - সনদ নম্বর
     - `{{ISSUE_DATE}}` - প্রদানের তারিখ
